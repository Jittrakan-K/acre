## 🔐 ระบบเข้าสู่ระบบ (รหัสพนักงาน + รหัสผ่าน)

ตั้งแต่เวอร์ชันนี้ ACRE ต้องเข้าสู่ระบบก่อนถึงจะเห็นข้อมูล ใช้ **รหัสพนักงาน + รหัสผ่าน** ผ่าน Firebase Authentication (แบบเดียวกับ CMMS) และฐานข้อมูลถูกล็อกด้วย `firestore.rules` ระบบ PIN เดิมเลิกใช้แล้ว

Firebase ต้องมีอีเมล ระบบจึงสร้างอีเมลเบื้องหลังที่ไม่มีใครใช้จริง (`…@acre.example.com`) และเก็บคู่ รหัสพนักงาน → อีเมล ไว้ใน `logins/{รหัสพนักงาน}`

### ตั้งค่าครั้งเดียว (ทำตามลำดับ)

1. **เปิด Email/Password** — https://console.firebase.google.com/project/orbray-techno-achievements/authentication › Get started (ถ้ายังไม่เคยเปิด) › แท็บ Sign-in method › Email/Password › Enable › Save
2. **Authorized domains** — แท็บ Settings › Authorized domains › ต้องมี `jittrakan-k.github.io` และ `orbray-techno-achievements.web.app` (ถ้าไม่มีให้ Add domain)
3. **ตั้งค่าครั้งแรกในเว็บ** — เปิด https://jittrakan-k.github.io/acre/ จะขึ้นหน้า "SET UP ACRE" ใส่ชื่อ รหัสพนักงาน (เช่น 20523) และรหัสผ่าน บัญชีนี้เป็นแอดมินคนแรก หน้านี้จะปิดถาวร
4. **สร้างบัญชีให้ทีม** — เมนูบัญชี › Team accounts › "Create their accounts" ระบบสร้างบัญชีให้ทุกคนในรายชื่อทีมเดิมและแสดงรหัสผ่านชั่วคราว 8 ตัว **ครั้งเดียว** ให้แจ้งแต่ละคน เข้าครั้งแรกต้องตั้งรหัสผ่านของตัวเอง
5. **นำเข้าข้อมูลงาน** — ในหน้าเดียวกัน กด "Import file" เลือก `acre-private-data.json` จากโฟลเดอร์ ACRE (ตารางติดตามงาน 325 แถว + รายการ Job Request 495 รายการ) ไฟล์นี้ไม่อยู่ใน GitHub
6. **เผยแพร่กฎความปลอดภัย** — Firestore Database › แท็บ Rules › ลบข้อความเดิมทั้งหมด › วางเนื้อหาไฟล์ `firestore.rules` ทั้งไฟล์ › Publish (ก่อนขั้นนี้ฐานข้อมูลยังเปิดให้ทุกคนอ่าน/เขียนได้เหมือนเดิม)
7. **ทดสอบ** — ออกจากระบบ แล้วเข้าด้วยบัญชีสมาชิกหนึ่งคน ตรวจว่าเห็นงานและแก้ไขได้

### สิทธิ์

| สิทธิ์ | ทำอะไรได้ |
| --- | --- |
| Admin | ทุกอย่าง + เพิ่มคน รีเซ็ตรหัสผ่าน เปลี่ยนสิทธิ์ ลบบัญชี นำเข้าข้อมูล |
| Member | ดู เพิ่ม แก้ไข ลบงาน เปลี่ยนรหัสผ่านตัวเอง |
| Visitor | ดูได้อย่างเดียว กดเพิ่มหรือแก้ไขงานจะขึ้นเตือนให้ติดต่อแอดมิน |
| Off | เข้าสู่ระบบได้แต่เห็นข้อมูลไม่ได้ (ใช้เมื่อพนักงานลาออก) |

แอดมินลดสิทธิ์หรือลบบัญชีตัวเองไม่ได้ เพื่อให้ระบบมีแอดมินเหลืออย่างน้อยหนึ่งคน แนะนำให้ตั้งแอดมินสำรองไว้อีกคน

- **เปลี่ยนรหัสผ่านเอง**: เมนูบัญชี › Change my password
- **ลืมรหัสผ่าน**: แอดมินกด Reset password ที่แถวของคนนั้น ระบบให้รหัสชั่วคราวใหม่ และรหัสเดิมใช้ไม่ได้ทันที (เบื้องหลังคือสร้างบัญชีล็อกอินใหม่ให้รหัสพนักงานเดิม บัญชีเก่าค้างใน Firebase › Authentication ลบทิ้งได้)
- รหัสพนักงานใช้ได้ A-Z 0-9 . _ - ยาว 2–20 ตัว รหัสผ่านอย่างน้อย 8 ตัว
